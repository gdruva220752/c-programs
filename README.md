# C Programs

A collection of single-file C programs.

| # | Program | Description |
|---|---------|-------------|
| 1 | [Time from Distance & Speed](time_from_distance_speed.c) | Calculates travel time given distance and speed. |
| 2 | [Seconds to HH:MM:SS](seconds_to_hms.c) | Converts elapsed seconds into hours, minutes, and seconds. |
| 3 | [Decimal Part Extractor](decimal_part.c) | Prints the decimal part of a floating-point number. |
| 4 | [Sum of Digits (3-digit)](sum_of_digits.c) | Sums the digits of a 3-digit number. |
| 5 | [Reverse a 3-digit Number](reverse_number.c) | Reverses the digits of a 3-digit number. |
